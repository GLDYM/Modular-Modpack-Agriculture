## 介绍

在以科技或冒险为核心的整合包、自组包和服务端整合包中，某些方向的模组只是作为必要组件而存在。对于这些既不重要、作者又不熟悉的模组，作者通常不会耗费过多精力去魔改。这使得这些模组在整合包中的表现往往不尽人意。

模块化整合包专注于某个主题的模组，并致力于解决这些相似主题模组之间的兼容性，统一各模组之间重复的内容。通过将一系列模组统筹整合后打包为模块，模块化整合包提供了一套可迁移的解决方案，而降低整合包作者在这些方向上的魔改压力。

模块化整合包不应该被直接使用，而应该作为自组包、公开发布整合包、服务器整合包的一部分使用。

## 使用

直接 Fork 本项目，或者安装这个整合包后将必要的文件移动到你的整合包内。注意模块化整合包需要一些必要的 Lib 模组以构建，因此你应该在你的整合包中去除这些重复的模组。

如果你只是想游玩这些模组，你需要一些基础整合包，如 超现代优化 或 浅忆基础整合，将所有文件复制到这些整合包中。

## 模组标准

### 通用标准

- 在 Curseforge 上发布。只在 Modrinth 上发布的模组难以支持。
- 不使用 MCreator 制作。
- 开源。闭源模组需要验证其稳定性。
- 尽可能积极维护。

### 本模块标准

- KubeJS 和 Rhino。
- 具有农业相关内容，或为必要的 Lib mod。
- 以非农业或 Lib 模组为前置的模组将不被接受，如 暮色风味乐事。
